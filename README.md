AI Chatbot

This project is a simple and interactive AI chatbot powered by the Google Gemini API. The chatbot allows users to communicate with an AI assistant and receive intelligent and helpful responses in real time.

The project is designed with a clean and user-friendly interface, making it easy for users to send messages and interact with the chatbot. It uses HTML, CSS, JavaScript, and PHP to create the interface, handle user interactions, and connect the application with the Gemini API.

The main goal of this project is to demonstrate how an AI-powered chatbot can be integrated into a web application using the Google Gemini API.
